# dz-catalog-analysis_gabdulhakov_m26-555
# Анализ каталога фильмов

Учебный проект по основам Python: консольный отчёт по каталогу фильмов.

## О проекте

Скрипт `catalog_analysis.py` содержит набор функций для анализа небольшого
каталога фильмов и собирает их в единый консольный отчёт:

- средняя оценка и средний возраст фильмов;
- топ-3 фильма по рейтингу;
- количество фильмов по каждому жанру;
- полный список уникальных жанров.

В проекте демонстрируются базовые конструкции Python: числа и `math`,
условия и `match`, циклы `for`/`while` с `break`/`continue`/`else`,
работа со строками, списками, словарями и множествами, а также
генераторы и генераторные выражения.

## Требования

- [uv](https://docs.astral.sh/uv/) версии 0.5 или новее
- Python 3.12 (версия зафиксирована в `.python-version`, uv подтянет её сам)
